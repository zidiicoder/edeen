TECHNICAL ISSUE REPORT - MOBILE APP API ACCESS BLOCKED
================================================================================

ISSUE SUMMARY:
Our React Native mobile application cannot access the API endpoints on 
api.edeenapp.co.uk because the CDN JavaScript challenge is still active on 
this subdomain, despite previous confirmation that it was disabled.

================================================================================
BACKGROUND:
================================================================================

Our mobile application (EDeen) was working correctly for 2 months. Recently, 
login and all API calls started failing with "Invalid credentials" errors.

After investigation, we discovered the root cause:
- Hostinger CDN Bot Protection is returning JavaScript challenge pages (HTTP 403)
- Mobile apps cannot execute JavaScript challenges (they are designed for browsers)
- This blocks ALL API requests from the mobile application

================================================================================
SOLUTION IMPLEMENTED:
================================================================================

Following Hostinger support guidance, we created a dedicated API subdomain:
- Subdomain: api.edeenapp.co.uk
- Purpose: Dedicated API endpoint with JavaScript challenge disabled
- Configuration: Points to /home/u402661558/domains/edeenapp.co.uk/laravel/public

Security approach agreed upon:
✓ Keep JavaScript Challenge ON for edeenapp.co.uk (main website)
✓ Turn JavaScript Challenge OFF for api.edeenapp.co.uk (API only)
✓ Keep WAF enabled for both
✓ API protected by Laravel authentication tokens + rate limiting

Hostinger support confirmed:
"The CDN settings for api.edeenapp.co.uk are now configured as requested:
- JavaScript Challenge: Disabled
- Web Application Firewall: Enabled
- WAF security level: 3"

================================================================================
CURRENT PROBLEM:

api.edeenapp.co.uk subdomain.
