═══════════════════════════════════════════════════════════════════
                       CASCADE BEHAVIOR
═══════════════════════════════════════════════════════════════════

ON DELETE CASCADE:
├─ Delete user → Deletes all user_settings
├─ Delete user → Deletes all habits
├─ Delete user → Deletes all habit_completions
├─ Delete user → Deletes all journal_entries
├─ Delete user → Deletes all reminders
└─ Delete habit → Deletes all habit_completions for that habit

ON UPDATE CASCADE:
└─ Update user.id → Updates all foreign key references

═══════════════════════════════════════════════════════════════════
                    INDEXING STRATEGY
═══════════════════════════════════════════════════════════════════

PRIMARY INDEXES:
All tables have auto-increment BIGINT UNSIGNED primary keys

FOREIGN KEY INDEXES:
All foreign keys automatically indexed for JOIN performance

LOOKUP INDEXES:
├─ users.email (for login)
├─ otps.email (for OTP verification)
├─ habits.user_id (for user habits)
├─ journal_entries.user_id + entry_date (for journal listing)
└─ reminders.user_id + is_active (for active reminders)

PERFORMANCE INDEXES:
├─ users.is_verified (for filtering verified users)
├─ habits.is_active (for active habits only)
├─ habits.frequency (for grouping by frequency)
└─ reminders.is_completed (for filtering tasks)
